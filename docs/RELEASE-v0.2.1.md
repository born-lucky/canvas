# A Quieter Canvas

Canvas now has a flat, early Macintosh/NeXT-inspired interface: a black title
bar, light-gray controls, white note fields, square borders, and compact type.
There are no gradients. Toolbar symbols have tooltips, selected notes are
highlighted, and work reports can collapse out of the way.

The overlay scrolls on shorter windows. Drawing and persistence tests passed
with real rendered captures at 1280x800 and 1024x600; Python tests also passed.

Download the Godot zip for the addon, or the framework zip for the protocol,
CLI, demo, tests, and AI integration guide. This update does not add other
engine adapters or live AI scene construction. The worker's local Windows
sandbox limitation described in 0.2.0 remains.

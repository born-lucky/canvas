# Show, Hide, Remove

Toggle all Canvas annotations without deleting their data, or save visibility
for each individual note. Clear a note's strokes while retaining its instruction,
or delete its saved note file with confirmation. Closing Canvas with F8 hides
the overlay and restores gameplay.

Hiding does not cancel queued AI tasks. Removing an annotation does not revert
AI changes to your game, and separate worker run logs remain as history.

The README includes new real Godot screenshots with annotations on and off.
Persistence, visibility, drawing clearing, and file deletion were tested.

Godot is the implemented adapter. Other adapters and live AI scene construction
are not included. Created by [born-lucky](https://github.com/born-lucky), MIT licensed.

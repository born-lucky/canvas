# Changelog

## 0.2.1

- Early Macintosh/NeXT-inspired flat monochrome interface, black title bar,
  white editing surfaces, compact typography, and crisp square borders.
- Recognizable toolbar symbols with tooltips, readable note IDs, and selected-note highlighting.
- Collapsible work reports and scrolling for shorter windows.
- Rendered drawing tests exercised at 1280x800 and 1024x600.

## 0.2.0

- Mouse-drawn 3D annotations on a camera-facing plane or collision surfaces.
- Ink color, drawing depth, stroke undo, object/source references, and editor display.
- Engine-independent protocol, JSON schema, and AI integration brief.
- CLI note creation and ID lookup for any project directory.
- Public MIT distribution, actual product screenshots, and creator credit.
- Permanent IDs, one file per note, legacy migration, and a local AI queue.

Godot is implemented; other adapters and live AI edits remain future work.

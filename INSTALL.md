# Install Canvas for Godot

1. Copy `addons/canvas` into your Godot 4.5+ project's `addons` folder.
2. Open Project Settings > Plugins and enable Canvas.
3. Run a 3D scene and press F8. Choose Draw and drag with the left mouse button.
4. Name the note, write its instruction, and save it. Notes stay in your project.

No Python or AI account is needed to annotate. The optional worker and other
engine integrations are documented at https://github.com/born-lucky/canvas.
Created by born-lucky. MIT licensed; retain the included notice.

Freehand capture is in play mode. The editor captures pins and displays drawings.
Object picking requires collision geometry. The worker edits project files;
live scene construction and automatic asset hot reload are not included.
